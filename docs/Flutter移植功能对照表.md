# NeriPlayer 功能对照表（原生 Android → Flutter）

> 本文档列出 NeriPlayer **全部功能点**，逐项对照原生实现与 Flutter 移植方案。
>
> - 数据来源：原项目 README、源码实测统计、已归档的历史文档（`docs/archive/`）
> - 更新时间：2026-09-16（补充私人FM/红心Radio、首页多源推荐）
> - 配套文档：`docs/转Flutter任务排期.md`（任务拆解与排期）

---

## 一、移植前提

| 项目 | 决定 |
|---|---|
| 目标平台 | **Android + Windows 桌面** |
| 实现方式 | **纯 Dart 实现**，不保留 Kotlin 原生模块（USB 已在裁剪范围内） |
| 服务端 | 一起听 Cloudflare Worker **原样复用，不做改动** |
| 授权协议 | 与原项目一致，GPL-3.0 |

---

## 二、图例

| 符号 | 含义 | 移植方式 |
|---|---|---|
| ✅ | **完整保留**，功能等价 | 直译（纯逻辑）或重写（UI） |
| 🟡 | **部分保留 / 降级实现**，括号内注明降级方式 | 降级 |
| ⚙️ | **需要平台通道**，Android 用原生插件、Windows 用 C++/系统 API | 平台通道 |
| 🔴 | **移除**，括号内注明原因 | 移除 |

> 说明：`⚙️` 不等于"做不到"，而是"Flutter 层做不了，需要一小段原生代码或成熟插件"。裁剪后这类项目已大幅减少。

## 六、需要在两个平台上分别处理的功能

这些不是"移除"，而是"两个平台做法完全不同"，需要写两套实现：

| 功能 | Android | Windows |
|---|---|---|
| 媒体控制中心 | `audio_service` + MediaSession | SMTC（`flutter_media_session` / `smtc_windows`） |
| 后台播放 | 前台服务 + WakeLock | 无此概念，窗口最小化到托盘 |
| 网页登录 | `webview_flutter` | `webview_windows`（WebView2） |
| 目录授权 | SAF（`file_picker`） | 直接路径 |
| 媒体库扫描 | MediaStore（`on_audio_query`） | 递归扫描文件系统 |
| 加密存储 | Android Keystore | Windows DPAPI |
| 触感反馈 | `HapticFeedback` | 无 |
| 网络类型识别 | Wi-Fi / 移动 / 漫游 | 有线 / Wi-Fi |
| 外部文件打开 | Intent Filter（VIEW/SEND） | 文件关联 |
| 深链 | Intent Filter | 注册 URI scheme |
| 桌面存在感 | 小组件（已砍） | 托盘 + 迷你窗口（新增） |
