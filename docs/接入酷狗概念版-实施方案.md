# NeriPlayer 接入酷狗概念版 · 实施方案（完整版）

> 状态：已定稿（待实施）· 2026-09-11
> 范围：完整版，含登录与 VIP 音质；**云盘 / 听歌历史 / 收藏**按用户决策暂缓
> 落地方式（用户决策）：**直接引入 [KuGouApi_Kotlin_SDK](https://github.com/ghhccghk/KuGouApi_Kotlin_SDK)（MIT）作为 SDK 依赖**，在其上封装 NeriPlayer 适配层
> 参考蓝本：EchoMusic（`D:\work\EchoMusic`）、[MakcRe/KuGouMusicApi](https://github.com/MakcRe/KuGouMusicApi)（MIT）

## 1. 结论摘要

- **可行**。NeriPlayer 已具备「直连国内音乐平台」的成熟模式（网易云全链路参照 [NeteaseClient.kt](../../app/src/main/java/moe/ouom/neriplayer/core/api/netease/NeteaseClient.kt)，含加密、QR 登录、音质回退），酷狗概念版的技术复杂度与之相当或更低。
- 参考 EchoMusic 的 **接口清单与风控策略**；其 Node.js server 代码不能直接复用，需按 Kotlin 重写（约 15~20 个核心模块即可支撑完整版）。
- **重大利好**：已存在 [KuGouApi_Kotlin_SDK](https://github.com/ghhccghk/KuGouApi_Kotlin_SDK) —— Kotlin/Android 侧实现，对齐 Android/iOS 的 MD5 + AES-CBC + RSA 加密，161 个接口、21 个模块，可作为直接参考甚至直接依赖，省去从 Node 翻译加密逻辑的工作。
- **主要风险**集中在两点：播放 URL 的签名与时效性、登录后的风控（验证码 / 账号风控），下文有专项方案。

## 2. 目标与边界

在本应用中新增独立的 **酷狗概念版源**，与现有网易云 / YouTube Music / B 站并列：

| 模块 | 说明 | 优先级 |
| --- | --- | --- |
| 搜索 | 歌曲 / 歌手 / 歌单 / 专辑搜索，挂接现有搜索入口 | P0 |
| 播放 | 免费音质（标准/128k/320k 视接口权限） | P0 |
| 歌词 | 复用现有酷狗概念版歌词链路（KugouLyricsClient），补 krc 解析 | P0 |
| 排行榜 / 热门榜 | 酷狗概念版榜单（飙升、新歌、热歌等） | P1 |
| 歌单 | 酷狗概念版歌单列表 / 详情 / 推荐 | P1 |
| 登录 | QR 登录 + 手机验证码登录（参考 NeteaseQrLoginClient） | P1 |
| VIP 音质 | 高音质 / 无损 / 超高（依赖登录态） | P1 |
| 私人 FM | 酷狗概念版 FM 推荐流 | P2 |
| 云盘 | 云盘音乐列表 / URL（依赖登录） | 暂缓（后续迭代） |
| 听歌历史 / 收藏 | 历史、收藏歌单、关注歌手（依赖登录） | 暂缓（后续迭代） |

边界与说明：
- 仅做「播放源」，不做酷狗概念版 App 的完整复刻；评论、MV、直播等不在本期范围。
- 酷狗概念版接口仅供个人学习研究，正式对外需关注版权与合规。

### 5.3 播放 URL（最核心）

| 能力 | 接口 | 说明 |
| --- | --- | --- |
| 免费播放 | `mobilecdn.kugou.com/api/v3/url`（`hash` + `album_id` + `mid/dfid` + `sig`） | 免费音质/试听；`sig=md5(hash+"kgcloudv2")` 一类，按蓝本实现 |
| 新播放引擎 | `v6/priv_url`（POST） | 全音质（320/flac/atmos），参数含 `key`（`hash+dfid+userid` 的 MD5，盐 `185672dd44712f60bb1736df5a377e82`）、`token`、`vip_token`（AES-256-CBC） |

播放 URL 获取策略（对应 [PlayerUrlResolver.kt](../../app/src/main/java/moe/ouom/neriplayer/core/player/url/PlayerUrlResolver.kt) 的网易云分支）：
1. 未登录 → `v3/url` 拿免费音质；
2. 已登录 → 优先 `v6/priv_url`，音质按用户设置降级（VIP 权限不足时逐级回落）；
3. 失败重试：权限不足 → 提示 VIP / 自动切源（见 §7）。

### 5.4 歌词

- 复用现有 [KugouLyricsClient.kt](../../app/src/main/java/moe/ouom/neriplayer/core/api/lyrics/KugouLyricsClient.kt)（`lyrics.kugou.com` 搜索 + `krc` 下载），补 `fmt=krc` 的 krc 解压解析（若现有实现未覆盖）。

## 6. 加密与签名（SDK 提供，项目侧仅理解不重写）

签名由 **KuGouApi_Kotlin_SDK** 封装（对齐 Android 端），项目侧只需了解其口令与限制以便排障：

| 算法 | 说明（SDK 内部实现） |
| --- | --- |
| `signatureAndroidParams(params, data)` | 密钥 `LnT6xpN3khm36zse0QzvmgTZ3waWdRSA`（lite 版）；参数 key 升序排序 → `k=v` join → `md5(secret + paramsStr + data + secret)` |
| `signatureWebParams(params)` | 密钥 `NVPh5oo715z5DIWAeQlhMDsWXXQV4hwt`，同上排序拼接 MD5 |
| `signatureRegisterParams(params)` | 设备注册专用，key 排序后 `md5(secret + paramsStr + secret)`（蓝本提供） |
| key（URL 请求） | `md5(hash + 盐 + appid + md5(dfid) + userid)`，盐 = `185672dd44712f60bb1736df5a377e82` |
| RSA（PKCS1 / NO_PADDING） | 登录 / token 加密（Android public key 取自蓝本/抓包） |
| AES-256-CBC | `vip_token` 及部分会话数据 |
| 设备指纹 | `mid`、`dfid`（注册响应下发或本地生成 `-xxxx-xxxx-xxxx`）、`uuid`；持久化复用同一身份 |

注意：
- **参数排序顺序错误会导致签名失败**，SDK 已对齐 Node 侧 `Object.keys().sort()` 行为（默认字典序）。
- 部分接口需要 `clienttime`（毫秒时间戳）参与签名，避免重放。
- 若 SDK 与项目技术栈/AGP 版本不适配或有缺失模块，按其算法公式自实现补充（蓝本公式存在于 KuGouMusicApi）。

## 7. 风控与登录态处理

酷狗概念版对非官方客户端有较高风控，EchoMusic 的处理经验可平移：

| 场景 | 酷狗概念版返回 | 处理策略 |
| --- | --- | --- |
| 滑块/极验/腾讯/网易易盾验证 | `error_code=20028` + `ssaCode`/`event_id` | 弹出验证组件 → 调 `/get/verify/info` → 用户完成 → 调 `/sidedt` 提交 → 重放原请求 |
| 账号风控 | `v_type=51`（ACCOUNT_RISK） | 提示「账号被酷狗概念版风控限制，请在酷狗概念版客户端完成申诉」，不做本地强解 |
| 手机验证码 / 绑定手机 | `v_type=36` | 引导用户完成绑定/验证码 |
| 人脸/实名 | `v_type=34` | 提示用户需实名认证，移交流程到官方 |
| 未登录听 VIP | 播放 URL 返回空/302 | 自动降级免费音质 + Toast 提示，可配置「自动切源」（复用网易云→B 站模式：酷狗概念版→B 站/网易云） |

风险缓解：
- 所有验证码 UI 走系统对话框/内嵌 WebView，与现有网易云登录弹窗风格一致。
- 请求频率控制：播放 URL 类接口限制 QPS（蓝本建议 3 QPS），避免被限流误判。
- token 过期自动刷新；刷新失败降级匿名态。

**阶段 0 实测协议要点（供适配层实现直接参考）：**
1. 设备注册 `auth.registerDev()` 返回 `{status:1, data:{dfid, mid, guid, serverDev, mac}}`，身份自动写入 SDK CookieJar。
2. 搜索 `search.search(keywords, page, pageSize)`（complexsearch 格式）：列表在 `data.lists[]`；每条关键字段为驼峰：`FileHash`（播放 hash）、`MixSongID`（album_audio_id）、`AlbumID`（album_id）、`FileName`（"歌手 - 歌名"）、`SingerName`。
3. 播放 URL `song.getSongUrl(hash, albumId, albumAudioId, quality="128")` 响应为**扁平结构**（非嵌套 data）：
   - `url: [String]` / `backupUrl: [String]` —— 顶层数组，取第一个即为直链；
   - `status: 1` 可播 / `2` 不可播；`priv_status: 1` 可播（另见 `fail_process:["pkg","buy"]` 提示 VIP/付费）；
   - 实测周杰伦等热门曲目全部 `status:2`（VIP），网络老歌（如《两只蝴蝶》）返回真实 128k mp3 直链 —— **免费源仅覆盖版权宽松曲目，VIP 曲目须登录+高音质接口（阶段 3）或切源（阶段 3 一并做）**。
4. 播放直链示例（设备绑定、有时效，勿长期复用）：`http://fs.youthandroid2.kugou.com/.../v3/{hash}/yp/full/ap3116_us0_..._pi411_mx{albumAudioId}_qu128_....mp3`

## 9. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 播放 URL 签名/密钥变更 | 播放功能失效 | 签名逻辑集中在一个 `KugouSigner`，密钥集中管理，便于热更；保留 Web 签名兜底 |
| 风控误伤（频繁验证码） | 体验差 | 限速 + 降级切源 + 明确提示 |
| 免费接口音质上限低 | VIP 歌曲听感差 | 引导登录；自动切源逃避版权阻塞 |
| KuGouApi_Kotlin_SDK 与项目技术栈兼容 | 集成成本 | 若 SDK 版权/版本不适配，按其算法自实现（有蓝本公式，自实现工作量可控） |
| 版权 / 合规 | 法律风险 | 仅供个人学习；README 声明；可屏蔽境内曲库若需合规 |
