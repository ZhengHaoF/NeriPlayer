# NeriPlayer 完整功能清单

## 项目概述

NeriPlayer 是一个基于 **Jetpack Compose + Media3** 的原生 Android 音频播放器，支持多源在线播放、本地音乐管理、丰富歌词体验和自建同步功能。

**技术支持**：Android 9 (API 28) 及以上设备  
**开源协议**：GPL-3.0  
**项目地址**：https://github.com/ZhengHaoF/NeriPlayer

---

## 核心功能

### 1. 多源在线播放

支持以下平台的在线音频播放：

- **网易云音乐**：搜索、播放、下载、歌词、歌单、专辑、艺术家
- **Bilibili**：视频搜索、收藏夹、合集、分P播放、下载
- **YouTube Music**：登录、搜索、播放兼容、PoToken支持
- **酷狗概念版**：搜索、多音质播放、扫码登录、资料库、歌词
- **QQ音乐**：探索搜索、匿名播放、排行榜、热门歌单、扫码登录、歌词
- **本地音频**：文件管理、播放、元数据识别

**关键特性**：
- 智能音源切换：网易云无权限时自动尝试降级音质，再匹配Bilibili或本地音频
- 播放失败自动重试：刷新当前链接，连续失败自动跳过
- YouTube播放多级回退：EJS/HLS回退机制
- Bilibili自定义跳过区间：支持SponsorBlock和自定义区间

### 2. 媒体库管理

**本地媒体库**：
- 系统音乐扫描和授权文件夹扫描
- 自动识别附近歌词和封面文件
- 本地歌手自动分类（支持feat.、with、和/与等分隔符）
- 本地歌手详情页：播放全部、多选、导出歌单、批量下载
- 本地歌单管理：创建、重命名、删除、排序、去重

**在线媒体库**：
- 网易云：歌单、专辑、艺术家详情、热门歌曲分页
- Bilibili：创建收藏夹、订阅收藏夹、合集管理
- YouTube Music：首页/媒体库歌单浏览
- QQ音乐/酷狗概念版：资料库账户内容、歌单详情

**收藏功能**：
- "我喜欢的音乐"系统歌单
- 收藏页支持歌单/歌手/热点分类
- 热点按个人收听记录生成周榜/月榜
- 网易云我喜欢的音乐同步

### 3. 搜索与探索

**分层搜索**：
- 按平台独立搜索：网易云/Bilibili/YouTube Music/酷狗概念版/QQ音乐
- 网易云支持歌曲/歌单/歌手分类搜索
- 网易云和Bilibili支持触底分页加载
- 本地搜索历史（可独立关闭）

**链接识别**：
- 支持直接链接和含短链接的分享文案
- 网易云：歌曲/歌单/歌手
- Bilibili：视频/收藏夹/合集/UP主（保留p/cid分P和season_id合集上下文）
- YouTube：视频/歌单/频道

**元数据补全**：
- 播放页自动补全封面、歌词和曲目信息
- 支持网易云/QQ音乐/LRCLIB外部歌词来源

### 4. 播放体验

**播放控制**：
- Media3 ExoPlayer播放核心
- 随机播放（真实乱序队列）、循环模式
- 睡眠定时器
- 淡入淡出、切歌交叉淡入淡出
- 长音频进度记忆（15分钟以上内容）
- 保留上次播放进度
- 恢复播放模式

**播放音效**：
- 倍速播放
- 音调调节
- 系统均衡器预设/手动频段
- 响度增强
- 按歌曲实时响度均衡
- 声道平衡
- 32-bit高解析普通输出

**播放失败兜底**：
- 网易云无权限时自动降级音质
- Bilibili DASH音频重试和html5/mp4渐进流回退
- 连续失败自动跳过或停止

### 5. 歌词系统

**歌词展示**：
- 逐行、逐词/逐字LRC歌词（含行尾时间和方括号逐字时间戳）
- YRC/TTML歌词支持
- 高亮、翻译歌词、音译显示
- 歌词偏移调节
- 点击跳转、长按分享
- 景深模糊、边缘渐隐
- 全屏歌词页

**歌词编辑**：
- 多平台手动匹配歌词（酷狗概念版/网易云/QQ音乐/AMLL TTML/LRCLIB/YouTube Music）
- 逐字歌词优先但不隐藏普通歌词
- 自动清理标题、制作信息等非歌词行
- 日语假名词汇翻译行间距优化

**歌词分享**：
- 逐行点选和范围选择
- 复制文本、分享歌曲
- 生成1080px歌词卡片

**外部歌词输出**：
- 悬浮歌词（可自定义颜色、描边、字号、位置、对齐）
- 状态栏歌词（部分设备）
- SuperLyric输出
- Lyricon Provider适配
- 蓝牙歌词（原文和翻译独立开关）

### 6. 下载管理

**下载功能**：
- 多平台音频下载
- 默认下载并发6，可调最高8
- 支持直接HTTP、分块Range、HLS下载
- 自动断点续传
- 启动时恢复未完成队列
- 已完成下载快速结算
- 下载完成后保留音频（即使标签写入失败）

**下载管理**：
- 下载列表管理
- 任务进度显示
- 取消/重试功能
- 下载目录索引
- 可迁移下载目录（应用私有目录/SAF自定义目录）
- 自定义文件名模板

**元数据后处理**：
- 保存歌词、封面、元数据和音频标签
- 可单独开关元信息后处理

### 7. 存储管理

**存储分析**：
- 分组统计：音频缓存、图片缓存、下载暂存、分享暂存、平台歌单缓存、下载内容、日志、崩溃报告、核心应用数据
- 存储占用详情查看

**缓存清理**：
- 只清理可再生成的缓存
- 不会删除用户主动下载的歌曲
- 支持分别清理：音频缓存、图片缓存、下载暂存、分享暂存、平台歌单缓存

### 8. 同步与备份

**GitHub同步**：
- 同步对象：本地歌单、收藏歌单、最近播放、播放统计、删除记录
- 使用WorkManager延迟与周期同步
- 延迟5秒同步 + 每小时周期同步
- 三路合并冲突处理
- 省流模式（GZIP(ProtoBuf)）
- 本地UUID设备标识
- Git Data API二进制blob提交

**WebDAV同步**：
- 同步对象与GitHub同步一致
- 支持自动同步和手动立即同步
- ETag/Last-Modified条件写入
- SHA-256指纹冲突检测

**备份与恢复**：
- 歌单JSON导入/导出
- 完整配置导入/导出（设置、语言、平台授权、同步配置）

## 技术架构

### 技术栈
- **UI框架**：Jetpack Compose
- **播放核心**：Media3 ExoPlayer
- **架构模式**：单Activity + Compose NavHost
- **本地存储**：DataStore、EncryptedSharedPreferences、文件系统
- **网络请求**：OkHttpClient
- **后台任务**：WorkManager
- **Native开发**：C++ (NDK 27.0.12077973)
- **构建工具**：CMake 3.28.0+

### 模块结构
- `:app`：主Android应用
- `:ksp-annotations` / `:ksp-processor`：设置项自动登记与生成
- `:accompanist-lyrics-core` / `:accompanist-lyrics-ui`：歌词解析与UI
- `build-logic`：统一Gradle convention plugin
- `buildSrc`：辅助Gradle构建逻辑
- `np-submodule/NeriPlayer-LTW`：一起听Cloudflare Workers服务端
- `np-submodule/miuix`：Miuix UI库源码/文档

### 代码组织
- `data/model/`：共享歌曲模型
- `playback/`：播放器核心
- `url/`：URL解析
- `resolver/`：音源解析器
- `service/`：播放服务
- `effects/`：音效处理
- `lifecycle/`：生命周期管理
- `watchdog/`：播放看门狗
- `usb/`：USB独占播放
- `sync/`：同步功能
- `download/`：下载管理
- `ui/`：Compose UI层

## 已知限制

### 网络
- 全局代理可能导致部分第三方接口返回异常数据

### 下载
- 不是系统级后台下载器
- 没有跨设备同步
- 手动取消下载会清理断点和半成品
- 自定义SAF目录性能较慢

### USB独占
- 仅支持UAC1.0和兼容UAC2.0 Type I PCM设备
- 依赖前台服务和系统后台策略
- UAC2异步链路仅接受唯一显式反馈端点和支持时钟拓扑

### 歌词
- 音译显示依赖平台或嵌入歌词中的音译数据
- 歌词卡片写入应用缓存目录
- 状态栏歌词仅部分设备支持

### 平台能力
- Bilibili不是完整视频发现流客户端
- QQ音乐和酷狗概念版平台风控可能导致功能临时不可用
- GitHub/WebDAV同步不是端到端加密

### 其他
- 长音频进度记忆不覆盖显式播放位置
- BilibiliSponsorBlock需要访问公开接口
- 一起听期间保持关闭

## 隐私说明

- 不提供公共云端媒体分发服务
- 不接入广告SDK、第三方统计或崩溃分析SDK
- 去中心化数据策略，用户自己控制同步目标
- 播放缓存、下载文件、本地歌单等默认保存在设备本地
- 不同步音频缓存、下载文件、Cookie、播放Token
- 不向第三方平台回写本地播放历史（账号安全考虑）
- 配置导出文件包含授权信息，应妥善保管
- 默认关闭Android系统云备份/设备迁移
